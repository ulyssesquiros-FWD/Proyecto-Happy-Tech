# Proyecto Happy Tech – Caso Finanzas

## 📌 Descripción
Este proyecto es parte de la práctica de **Ingeniería de Prompts**.  
El objetivo es resolver un problema real de negocio usando IA y programación colaborativa en GitHub.

**Caso elegido:** Finanzas  
- Empresa: Happy Tech (venta de hardware de computación y tecnología).  
- Problema: Extraer datos clave de descripciones de gastos en texto libre y clasificarlos por rubro para un reporte.  
- Restricción: No incluir artículos de procedencia china.  

## 🛠️ Herramientas utilizadas
- ChatGPT / Claude / Gemini (IA generativa)  
- Visual Studio Code  
- GitHub (flujo de ramas y Pull Requests)  
- Node.js (JavaScript)
